# Studio Web

Site vitrine responsive présentant des services et tarifs de création de sites web.

## Prévisualisation

Ouvrez `apercu.html` pour afficher le site simultanément sur un ordinateur
et sur un téléphone portable.

Dans VS Code :

1. Ouvrez le dossier `mon-site`.
2. Cliquez avec le bouton droit sur `apercu.html`.
3. Choisissez **Open with Live Server** si l'extension Live Server est installée.

Vous pouvez également lancer un serveur local dans le terminal de VS Code :

```bash
python3 -m http.server 8080
```

Puis ouvrez `http://localhost:8080/apercu.html`.
